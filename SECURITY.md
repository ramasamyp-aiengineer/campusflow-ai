# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner. Do not
open a public issue or include secrets, personal data, or exploit details in logs.

Include the affected route or component, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within three business
days. Please allow time for a fix and deployment before public disclosure.

## Supported version

Security fixes are applied to the current `main` branch and the currently deployed
CampusFlow service. Older local copies are not supported.
